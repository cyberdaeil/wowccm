# WOWCCM 와플 (WOWCCM Wapl) 브랜딩

플레이어의 공식 이름은 **WOWCCM 와플**입니다. "와우플레이어"를 줄인 이름이고, 아이콘도 와플 모양입니다.
이전 플레이어의 사연 코너 "Wapl Letter", 게시판 `wapl_memo`와 같은 이름입니다.

| 파일 | 쓰는 곳 |
|---|---|
| `wapl-icon-source.png` (1024×1024) | 원본. 64px 이상 아이콘(설치 파일, Mac Dock, 앱 목록) |
| `wapl-icon-small.png` | 와플 부분을 확대한 것. 48px 이하 아이콘(작업 표시줄, 트레이, 창 모서리). 작은 크기에서 주황 배경에 묻히지 않게 함 |

정식판(v2.0.0)에서 `src-tauri/icons/` 아이콘을 이 그림들로 교체할 예정입니다.
