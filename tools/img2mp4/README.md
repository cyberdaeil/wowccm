# 사진 → 영상 만들기

사진 한 장(+ 음악)으로 mp4를 만드는 웹 페이지입니다. **`index.html` 파일 하나**입니다.
더블클릭하면 크롬이나 엣지에서 바로 열립니다. 서버도 설치도 필요 없고, 변환은 브라우저 안에서 일어납니다.

- 길이: 30초 / 1분 / 1분 30초 / 2분
- 크기: 가로 1920×1080, 세로 1080×1920
- 음악: 선택. 짧으면 반복, 길면 자르고, 끝 2초는 서서히 작아집니다.
- 필요한 것: 최신 크롬 또는 엣지 (WebCodecs 사용)

mp4 생성 부분은 [mp4-muxer](https://github.com/Vanilagy/mp4-muxer) 5.1.3 (MIT)을 파일 안에 포함했습니다.
